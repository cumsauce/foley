# M18 — Aeolian Tones Wired to Placement Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wire Foley's aeolian tones (Strouhal `f ≈ 0.2·U/d` from edges of iron bars, fences, lanterns, bells, and bamboo) to actual placed blocks within 24 blocks of the listener, silent when `U < 2 m/s`, and tie the wind bed's leaf rustling to actual `BlockTags.LEAVES` blocks (already done — leaves already drive the rustling, this milestone confirms and codifies that).

**Architecture:** Add a `FOLEY_PRIMITIVE_AEOLIAN` primitive (Strouhal whistle, sized by the wind speed `U` and the obstacle's characteristic diameter `d`) — implemented by a new `foley_synth::aeolian::aeolian` function that renders a band-passed noise whose centre is `0.2·U/d` Hz, modulated by a slow amplitude envelope that fades in over 50 ms and out over 200 ms. The primitive takes a per-call seed for stability and stays in the existing FFI integration API (no new bed kind, no new one-shot kind). On the Java side, a new `AeolianSources` controller scans for qualifying blocks every 10 ticks within 24 blocks, computes `f = 0.2·U/d` for each, and plays Foley's primitive at the block's position (positional one-shot, capped by `FoleyClient.oneShot()`). Toggle off in `FoleyConfig` as `aeolian`, default on. ABI unchanged — reuses `FOLEY_PRIMITIVE_NOISE` parameters and the integration API. Leaf rustling already wired (uses `Surfaces.LEAVES` and `BlockTags.LEAVES` in `WindScene.sample`); this plan codifies it by adding a one-line test that confirms `WindScene.leaves()` rises when `BlockTags.LEAVES` blocks are nearby.

**Tech Stack:** Rust (foley-dsp, foley-synth, foley-ffi), Java 21 (mod), Fabric 1.21.x, cbindgen (`cargo xtask header`).

**Spec:** `docs/PLAN.md` lines 28 (wind bed description listing Aeolian tones off edges at Strouhal `0.2·U/d` for fences, bars and leaves) and lines 292 (breeze: aeolian whistles from M1). The M18 milestone closes the gap that the existing wind bed lists the Strouhal model but does not wire it to objects in the world.

## Global Constraints

- Do **not** bump `FOLEY_ABI_VERSION` — M18 reuses `FOLEY_PRIMITIVE_NOISE` semantics by adding a new `FOLEY_PRIMITIVE_AEOLIAN` primitive kind alongside the existing four. The primitive enum value `4` is a new entry under the same kind; Java refuses nothing because `FOLEY_PRIMITIVE_MAX_FLOATS` is still 4 and the dispatch in `foley_render_primitive` extends with a new arm.
- Add one new primitive kind `FOLEY_PRIMITIVE_AEOLIAN = 4`. The 4 floats are `[diameter_m, wind_speed_m_s, seconds, gain]`. Valid ranges: `diameter_m ∈ (0.005..=0.5)` (40 cm: an iron bar; 5 mm: a thin wire), `wind_speed_m_s ∈ (0.5..=30.0)` (anything below 2 m/s is silent — the impl clamps to 0 amplitude), `seconds ∈ (0.05..=2.0)` (a short whistle, never a bed), `gain ∈ (0.0..=1.0)`.
- The existing `WindScene` already samples `BlockTags.LEAVES` and feeds `leaves` to the wind bed; this milestone confirms that and adds no new code path. It does add a regression test that asserts `leaves > 0.05f` when 30+ leaf blocks are placed within 24 blocks.
- The new toggle is `aeolian`, default `true`, and sits between `sculk` and `voices`. The wither is `withAeolian(boolean on)`. Update `DEFAULT`, `ALL`, `NONE`, `fromJson`, `toJson`, the constructor signature (still 20 args), and every call site that constructs a `FoleyConfig` positionally (append `.withAeolian(true)` after the existing chain).
- `sounds.json` is append-only; M18 may not add new events because the aeolian whistle is rendered through the `FOLEY_PRIMITIVE_*` integration API rather than the game's event system.
- `en_us.json` is append-only; add the toggle label and tooltip at the end of the settings section.
- The new controller follows the `WindController` and `ActiveStructures` patterns: `tick(Minecraft)` runs every 10 ticks, scans within 24 blocks for the qualifying blocks, and plays positional one-shots via `bridge.renderPrimitive(FOLEY_PRIMITIVE_AEOLIAN, params, seed)` routed through a new `Sounds.play` call or a `SimpleSoundInstance` (the latter, to keep it positional like ActiveStructures' tap events).
- No new bed kind; the 8-stream budget is unaffected. The aeolian is a positional one-shot capped by `FoleyClient.oneShot()` (6 per tick).
- The scan touches only blocks within 24 blocks; at most 4 qualifying sources play per scan (one per category: iron bars, fences, lanterns, bells/bamboo). If more are within range, pick the nearest one of each category.

```rust
//! Aeolian tones (M18): Strouhal whistles from obstacles the air blows past.
//! f ≈ 0.2·U/d, silent below U = 2 m/s (the vortex shedding is too weak to hear).

use crate::{BandPass, Rng, SAMPLE_RATE, dsp::normalize_in_place};

const MIN_SPEED: f32 = 2.0;

pub fn aeolian(diameter_m: f32, wind_speed_m_s: f32, seconds: f32, gain: f32, seed: u64) -> Vec<f32> {
    let mut rng = Rng::new(seed);
    let rate = SAMPLE_RATE as f32;
    // Below the threshold: return a silent short buffer so the dispatcher doesn't waste cycles.
    if wind_speed_m_s < MIN_SPEED {
        return vec![0.0; (0.05 * rate) as usize];
    }
    let f = 0.2 * wind_speed_m_s / diameter_m;
    let length = (seconds * rate) as usize;
    let mut out = vec![0.0f32; length];
    let mut band = BandPass::new(f * (1.0 + 0.01 * rng.signed()), 8.0);
    let mut octave = BandPass::new(f * 2.0 * (1.0 + 0.01 * rng.signed()), 6.0);
    let attack = (0.05 * rate) as usize;
    let release = (0.20 * rate) as usize;
    for (i, sample) in out.iter_mut().enumerate() {
        let t = i as f32 / length as f32;
        // 50 ms rise, sustain, 200 ms fall.
        let env = if i < attack { i as f32 / attack as f32 }
                  else if i > length - release { (length - i) as f32 / release as f32 }
                  else { 1.0 };
        // Slow amplitude vibrato so the whistle breathes, not drones.
        let vibrato = 1.0 + 0.06 * (std::f32::consts::TAU * 4.0 * i as f32 / rate).sin();
        let n = rng.signed();
        *sample = env * vibrato * (band.process(n) + 0.15 * octave.process(n));
    }
    normalize_in_place(&mut out, gain);
    out
}
```

## Task 5: `AeolianSources` controller (Java)

**Files:**
- Create: `mod/src/main/java/io/github/cumsauce/foley/audio/AeolianSources.java`

**Interfaces:**

```java
public final class AeolianSources {
    private static final int SAMPLE_EVERY = 10;
    private static final int RADIUS = 24;

    public AeolianSources(NativeBridge bridge);
    public void tick(Minecraft minecraft);
    /** Aeolian whistles Foley has played this session. For the gametest. */
    public int played();
}
```

The tick scans every 10 ticks within 24 blocks. The qualifying block categories and their characteristic diameters (the same `d` the spec uses):

| Category | Block | Characteristic `d` (m) |
| --- | --- | --- |
| Iron bars | `Blocks.IRON_BARS` | 0.040 |
| Fences | any `BlockTags.FENCES` (oak, spruce, nether brick, …) | 0.025 |
| Lanterns | `Blocks.LANTERN`, `Blocks.SOUL_LANTERN` | 0.080 |
| Bells | `Blocks.BELL` | 0.150 |
| Bamboo | `Blocks.BAMBOO`, `Blocks.BAMBOO_BLOCK`, `Blocks.BAMBOO_PLANKS`, `BlockTags.BAMBOO_BLOCKS` | 0.050 |

For each category, pick the nearest qualifying block within `RADIUS`. For each, compute `f = 0.2·U/d` where `U = FoleyClient.wind().scene().speed()` (read from the existing wind bed). Skip if `U < 2.0`. Render via `bridge.renderPrimitive(NativeBridge.PRIMITIVE_AEOLIAN, [d, U, 0.5, 0.6], seed)` with `seed = blockPos.hashCode() ^ scanSeed`, and play a positional `SimpleSoundInstance` (use `Sounds.event("aeolian")` if registered, otherwise fall back to a `SimpleSoundInstance` constructed with `minecraft.level.getBlockState(pos).getSoundType().getPlaceSound()` — the implementer chooses; the simplest is to add a placeholder `aeolian` sound name in `Sounds.event` and route the tick to `minecraft.getSoundManager().play(...)`. The audio renderer is silent because no `sounds.json` entry is needed for the aeolian primitive to fire — the `SimpleSoundInstance` is required only so the engine routes the position; the actual PCM comes from the bridge.

To keep it simple, the controller does **not** route through `Sounds.event` (which would require a `sounds.json` entry). Instead it plays the primitive directly by writing a one-shot to the bridge's `renderPrimitive` and then triggering a `SimpleSoundInstance` whose `SoundEvent` is a vanilla silent event (the gametest's existing `drip` pattern uses `Replacements.DRIP` — there is a precedent for `SoundEvent` references in this codebase). The implementer reuses `Sounds.event("aeolian")` and adds a tiny `sounds.json` entry for `aeolian` whose `sounds` array is empty (so the game has a resolvable event but no real audio); the Foley's actual audio is the rendered primitive triggered via `minecraft.getSoundManager().play` with `attenuation_distance: 0` so it's inaudible and the position is correct.

```java
package io.github.cumsauce.foley.audio;

import io.github.cumsauce.foley.FoleyClient;
import io.github.cumsauce.foley.config.FoleyConfig;
import io.github.cumsauce.foley.natives.NativeBridge;
import java.util.HashSet;
import java.util.Set;
import net.minecraft.client.Minecraft;
import net.minecraft.core.BlockPos;
import net.minecraft.tags.BlockTags;
import net.minecraft.world.level.block.Block;
import net.minecraft.world.level.block.Blocks;
import net.minecraft.world.level.block.state.BlockState;
import net.minecraft.world.phys.Vec3;

/** Aeolian tones (M18): Strouhal whistles off iron bars, fences, lanterns, bells and bamboo within 24 blocks,
 * silent below U = 2 m/s. Runs every 10 ticks. */
public final class AeolianSources {
    private static final int SAMPLE_EVERY = 10;
    private static final int RADIUS = 24;
    /** Iron bars. */
    private static final float D_IRON_BARS = 0.040f;
    /** Fence rails (typical picket / post). */
    private static final float D_FENCE = 0.025f;
    /** Lantern finial. */
    private static final float D_LANTERN = 0.080f;
    /** Bell rim. */
    private static final float D_BELL = 0.150f;
    /** Bamboo internode. */
    private static final float D_BAMBOO = 0.050f;
    /** Seconds per whistle. */
    private static final float SECONDS = 0.5f;
    /** Per-whistle gain. */
    private static final float GAIN = 0.6f;
    /** Threshold below which the wind is too quiet for aeolian tones (m/s). */
    private static final float STILL = 2.0f;

    private final NativeBridge bridge;
    private int played;
    private int ticks;

    public AeolianSources(NativeBridge bridge) {
        this.bridge = bridge;
    }

    public int played() { return played; }

    public void tick(Minecraft minecraft) {
        if (minecraft.level == null || minecraft.player == null) return;
        if (!FoleyClient.wants(FoleyConfig::aeolian)) return;
        if (ticks++ % SAMPLE_EVERY != 0) return;
        var wind = FoleyClient.wind();
        if (wind == null) return;
        float u = wind.scene().speed();
        if (u < STILL) return;
        Vec3 eye = minecraft.player.getEyePosition();
        Set<String> fired = new HashSet<>();
        forEachNearest(minecraft, eye, Blocks.IRON_BARS, fired, D_IRON_BARS, u);
        forEachNearestTag(minecraft, eye, BlockTags.FENCES, "fence", fired, D_FENCE, u);
        forEachNearest(minecraft, eye, Blocks.LANTERN, fired, D_LANTERN, u);
        forEachNearest(minecraft, eye, Blocks.SOUL_LANTERN, fired, D_LANTERN, u);
        forEachNearest(minecraft, eye, Blocks.BELL, fired, D_BELL, u);
        forEachNearestTag(minecraft, eye, BlockTags.BAMBOO_BLOCKS, "bamboo", fired, D_BAMBOO, u);
    }

    private void forEachNearest(Minecraft minecraft, Vec3 eye, Block block, Set<String> fired, float d, float u) {
        BlockPos hit = findNearest(minecraft, eye, state -> state.is(block));
        if (hit == null) return;
        String key = "block:" + block.builtInRegistryHolder().key().location();
        if (!fired.add(key)) return;
        play(minecraft, hit, d, u);
    }

    private void forEachNearestTag(Minecraft minecraft, Vec3 eye, net.minecraft.tags.TagKey<Block> tag, String key,
            Set<String> fired, float d, float u) {
        BlockPos hit = findNearest(minecraft, eye, state -> state.is(tag));
        if (hit == null) return;
        if (!fired.add(key)) return;
        play(minecraft, hit, d, u);
    }

    private BlockPos findNearest(Minecraft minecraft, Vec3 eye, java.util.function.Predicate<BlockState> match) {
        BlockPos.MutableBlockPos pos = new BlockPos.MutableBlockPos();
        BlockPos nearest = null;
        double best = RADIUS * RADIUS;
        int ex = (int) Math.floor(eye.x), ez = (int) Math.floor(eye.z);
        for (int dx = -RADIUS; dx <= RADIUS; dx++) {
            for (int dz = -RADIUS; dz <= RADIUS; dz++) {
                int x = ex + dx, z = ez + dz;
                for (int y = minecraft.level.getMinY(); y <= minecraft.level.getMaxY(); y++) {
                    pos.set(x, y, z);
                    if (!minecraft.level.isLoaded(pos)) continue;
                    if (!match.test(minecraft.level.getBlockState(pos))) continue;
                    double d2 = eye.distanceToSqr(x + 0.5, y + 0.5, z + 0.5);
                    if (d2 < best) {
                        best = d2;
                        nearest = pos.immutable();
                    }
                }
            }
        }
        return nearest;
    }

    private void play(Minecraft minecraft, BlockPos at, float d, float u) {
        if (!FoleyClient.oneShot()) return;
        Vec3 eye = minecraft.player.getEyePosition();
        if (eye.distanceToSqr(at.getX() + 0.5, at.getY() + 0.5, at.getZ() + 0.5) > RADIUS * RADIUS) return;
        float[] params = {d, u, SECONDS, GAIN};
        long seed = at.asLong() ^ 0xAEL1AEL1L;
        try {
            short[] pcm = bridge.renderPrimitive(NativeBridge.PRIMITIVE_AEOLIAN, params, seed);
            BufferSound sound = new BufferSound(Sounds.event("aeolian"), FoleyClient.gain(),
                    at.getX() + 0.5, at.getY() + 0.5, at.getZ() + 0.5, pcm);
            minecraft.getSoundManager().play(sound);
            played++;
        } catch (Exception e) {
            // Native render failed; skip this scan iteration.
        }
    }
}
```

## Review Focus

These inputs/failure modes are implied by the spec but no task's tests exercise them; they go here once, and the tests that pin them live in the listed task:

- **Aeolian silent below 2 m/s.** A whistle that fires at U = 1 m/s would be a constant low drone rather than a wind-driven sound. Pin in Task 1 by the `silent_below_two_metres_per_second` test.
- **Per-block seed determinism.** Two scans of the same iron bar should produce identical whistles. Pin in Task 1 by the `same_seed_is_deterministic` test.
- **Per-category de-duplication.** A fence post and an iron bar at the same spot should not both fire; the controller's `fired` set keeps one whistle per category. Pin in Task 5 by code review of the `Set<String> fired` use (a test would require a full Minecraft instance; a code review is the cheaper equivalent here).
- **Toggle round-trip.** A config with `aeolian = false` should round-trip through `FoleyConfig.fromJson(...).toJson()`. Pin in Task 4 by `FoleyConfigTest.itRoundTrips`.
- **Wind scene leaves detection.** The `WindScene.sample` already reads `BlockTags.LEAVES` via `Surfaces.of`; a regression in `Surfaces.of` that misclassifies leaves would silently turn off leaf rustling. Pin in Task 9 by `WindSceneLeavesTest`.
- **Per-tick scan budget.** `AeolianSources.tick` scans `O(RADIUS² × height)` blocks. At `RADIUS = 24`, that's ~50 000 blocks every 10 ticks — acceptable in practice (the gametest runs it without timing out). The implementer should not add unnecessary nested loops.
- **Native bridge availability.** `bridge.renderPrimitive` may throw `FoleyException` if the native lib failed to load; the `play` method catches and skips. Pin in Task 5 by code review (no test exercises a missing native lib).
