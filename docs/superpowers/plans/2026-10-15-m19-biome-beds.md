# M19 — Biome-specific Beds Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Foley makes six biomes audible: desert hiss, mushroom hum, lush/dripstone cave colors, deep dark subsonic drone, snowy hush, and mangrove insect drone. Each is a per-biome bed (a new `FOLEY_BED_BIOME` kind) driven by the listener's current biome, and gated by a new `FoleyConfig` toggle.

**Architecture:** A new Rust bed kind `FOLEY_BED_BIOME` (index 6) takes four floats: a `kind` (0=desert, 1=mushroom, 2=lush, 3=dripstone, 4=deep_dark, 5=snow, 6=mangrove), `intensity` (how much of the biome is around the ear, 0 to 1), `sub` (a sub-parameter — desert vortex count, mangrove leaf count, deep_dark scuttle count, snow leaf exposure, mushroom warmth), and a 4th unused float. Each `kind` is a small streaming mixer in `crates/foley-synth/src/biome.rs`, all sharing `SAMPLE_RATE` mono. A new `BiomeController` Java class ticks at 5-tick cadence, samples the biome at the listener's ear, and runs a single `BedSound<BiomeScene>` through `SurroundBeds`. The umbrella toggle is `biomeBeds`; six sub-toggles (per biome) let players switch individual ones off. Default all on, like the M21 toggles.

**Tech Stack:** Rust (foley-synth, foley-ffi), Java 21 (mod), Fabric 1.21.x, cbindgen (`cargo xtask header`).

**Spec:** `docs/PLAN.md` line 6 (Foley's overall spec) and the brief section "M19 (biome-specific beds)"; no prior M19 plan exists in the repo — this is the plan.

## Global Constraints

- Bump `FOLEY_ABI_VERSION` from **20** to **21** in `crates/foley-ffi/src/lib.rs` and `crates/foley-ffi/include/foley.h`, and the Java `NativeBridge.ABI_VERSION` from 20 to 21. Java refuses a library whose version differs. (Reason: the new `FOLEY_BED_BIOME = 6` is a new bed kind; the FFI must advertise it.)
- Add one new bed kind: `FOLEY_BED_BIOME = 6`. The bed takes 4 floats, all checked like every other bed's params:
  - `kind` (0 to 6, integer-valued; 0 desert, 1 mushroom, 2 lush, 3 dripstone, 4 deep_dark, 5 snow, 6 mangrove);
  - `intensity` (0 to 1): how much of the biome the listener is in (1 = centered, 0.3 = edge);
  - `sub` (0 to 200): a kind-specific count (vortex rings per 30 s for desert, leaf count / 16 for mangrove, etc.);
  - `gain` (0 to 1): the bed's master gain (so a player-side volume can mute a single biome).
- M19 adds **seven** new `FoleyConfig` booleans after `sculk` and before `voices`: an umbrella `biomeBeds` plus six per-biome `desertBeds`, `mushroomHum`, `caveColors`, `deepDark`, `snowyHush`, `mangroveDrone`. All default `true`. The umbrella's value follows: `umbrella = biomeBeds && (desertBeds || mushroomHum || caveColors || deepDark || snowyHush || mangroveDrone)`. Each toggle gets a wither; the umbrella gate is applied in `BiomeController.tick` so the bed stops when none of the per-biome toggles are on, regardless of the umbrella.

- [ ] **Step 3: Implement `biome.rs` with the 7 sub-renderers**

Each sub-renderer is a simple, deterministic, small mixer:

- **Desert** (`Desert`): granular hiss of band-passed noise centred at ~6 kHz, Q ~0.7, the count of grains per second ∝ `intensity * 200` (a few hundred grains a second underfoot). The wind in the open plain: a high-Q whistle at ~1.5 kHz, the loudness ∝ `intensity` and only on `sub > 0`. Vortex rings (dust devils): every 30 s when `intensity > 0.6` and `sub > 0`, a low vortex whoosh (band-passed noise centred at 200 Hz, Q 1.2, 1.5 s, swept up and down). The vortex count is `floor(sub / 30)` per 30 s.
- **Mushroom** (`Mushroom`): very quiet low hum at 120 Hz + 1.6× overtone (192 Hz), each a slow sine, mixed at low gain ∝ `intensity` (peak 0.05). Plus a faint band-passed noise at 300 Hz, Q 4, to suggest air movement. Length is foreshortened: the render never has a sub-render; it just runs.
- **Lush** (`Lush`): keep the wind bed's tone but raise the centre to 4 kHz (high-frequency moss hiss). Lighter texture (less low rumble) and more high-frequency content. A `noise_burst` per 0.3 s at centre 4000, Q 0.7, gain ∝ `intensity * 0.4`.
- **Dripstone** (`Dripstone`): more drips and less rumble. Drips: every 2 s a `bubble` primitive at radius 4 mm, gain 0.6. Background: a very low rumble at 80 Hz, gain 0.05.
- **Deep dark** (`DeepDark`): a 30 Hz subsonic hum (sine, gain 0.4 × intensity). Sub-render: every 30 s a scuttle — band-passed noise centred at 2 kHz, Q 0.5, 0.4 s, gain 0.3. Count `sub` per 30 s.
- **Snow** (`Snow`): a high-frequency absorption LPF applied to the bed's output: a one-pole LPF at `4000 - 2000 * intensity` Hz. The bed mixes band-passed noise centred at 2000 Hz, Q 0.5 (the wind, muffled). Below 4 kHz the listener hears; above 4 kHz, it cuts. Less in lighter intensity; full at intensity 1.
- **Mangrove** (`Mangrove`): band-passed noise centred at 4 kHz, Q 0.6, level ∝ `intensity * (sub / 200)` (a humid insect drone). Layered: a low 100 Hz drone at gain 0.05, the 4 kHz drone at gain `min(0.5, sub / 100 * 0.05)`. Length: 48000 samples (1 s) is plenty.

State is held in a small `BiomeState` enum (one variant per kind) so the dispatch happens once per `set_scene`, not per `render`. The `gain` is multiplied into the final output. Everything is `f32`, mono, `SAMPLE_RATE`. `SAMPLE_RATE = 48_000` (from `foley-dsp`). The bed is a single struct (not six): one bed plays the biome that the listener is in; the controller picks the kind and starts a new bed when the biome changes (the `BiomeController` re-creates the bed on biome change, not the synth).

```java
package io.github.cumsauce.foley.audio;

import io.github.cumsauce.foley.FoleyClient;
import io.github.cumsauce.foley.config.FoleyConfig;
import net.minecraft.client.Minecraft;
import net.minecraft.core.BlockPos;
import net.minecraft.core.Holder;
import net.minecraft.sounds.SoundSource;
import net.minecraft.tags.BiomeTags;
import net.minecraft.world.level.biome.Biome;
import net.minecraft.world.level.biome.Biomes;
import org.jspecify.annotations.Nullable;

/** M19: per-biome ambient beds (desert hiss, mushroom hum, lush/dripstone cave colors, deep dark, snow hush, mangrove drone). */
public final class BiomeController {
    private static final int SAMPLE_EVERY = 5;

    private final SurroundBeds<BiomeScene> beds;
    private BiomeScene scene = BiomeScene.SILENT;
    private int ticks;

    public BiomeController(NativeBridge bridge) {
        this.beds = new SurroundBeds<>("biome", SoundSource.AMBIENT, bridge, NativeBridge.BED_BIOME);
    }

    public BiomeScene scene() { return scene; }
    public @Nullable BedSound<BiomeScene> sound() { return beds.any(); }

    public void tick(Minecraft minecraft) {
        if (minecraft.level == null || minecraft.player == null) {
            stop(minecraft);
            return;
        }
        if (ticks++ % SAMPLE_EVERY != 0) return;
        BiomeScene sampled = sample(minecraft);
        scene = sampled;
        if (sampled.gain() <= 0f) {
            stop(minecraft);
            return;
        }
        beds.keep(minecraft, scene, new float[]{1f, 1f, 1f, 1f});
    }

    private void stop(Minecraft minecraft) { beds.stop(minecraft); }

    private static BiomeScene sample(Minecraft minecraft) {
        var player = minecraft.player;
        if (player == null) return BiomeScene.SILENT;
        var level = minecraft.level;
        if (level == null || !level.dimensionType().hasSkyLight()) return BiomeScene.SILENT;
        Holder<Biome> biome = level.getBiome(BlockPos.containing(player.getEyePosition()));
        float celsius = 20 * biome.value().getBaseTemperature();
        // Default: nothing.
        int kind = -1;
        float intensity = 0f;
        float sub = 0f;
        if (biome.is(Biomes.DESERT) || biome.is(Biomes.BADLANDS) || biome.is(Biomes.ERODED_BADLANDS)
                || biome.is(Biomes.WOODED_BADLANDS) || biome.is(Biomes.BAMBOO_JUNGLE)) {
            // Desert hiss (jungle has its own mossy bed via the lush; bamboo uses jungle).
            // Badlands and desert share the bed.
            if (biome.is(Biomes.DESERT) || biome.is(Biomes.BADLANDS) || biome.is(Biomes.ERODED_BADLANDS)
                    || biome.is(Biomes.WOODED_BADLANDS)) {
                if (!FoleyClient.wants(FoleyConfig::desertBeds)) return BiomeScene.SILENT;
                kind = BiomeScene.DESERT;
                intensity = 1f;
                // `sub` = vortex rings per 30 s, capped at 2 by spec; only when U > 8 m/s.
                var wind = FoleyClient.wind();
                float speed = wind == null ? 0f : wind.scene().speed();
                sub = speed > 8f ? Math.min(2f, (speed - 8f) * 0.5f) : 0f;
            }
        } else if (biome.is(Biomes.MUSHROOM_FIELDS)) {
            if (!FoleyClient.wants(FoleyConfig::mushroomHum)) return BiomeScene.SILENT;
            kind = BiomeScene.MUSHROOM;
            intensity = 1f;
            sub = 0f;
        } else if (biome.is(Biomes.LUSH_CAVES)) {
            if (!FoleyClient.wants(FoleyConfig::caveColors)) return BiomeScene.SILENT;
            kind = BiomeScene.LUSH;
            intensity = 1f;
            sub = 0f;
        } else if (biome.is(Biomes.DRIPSTONE_CAVES)) {
            if (!FoleyClient.wants(FoleyConfig::caveColors)) return BiomeScene.SILENT;
            kind = BiomeScene.DRIPSTONE;
            intensity = 1f;
            sub = 0f;
        } else if (biome.is(Biomes.DEEP_DARK)) {
            if (!FoleyClient.wants(FoleyConfig::deepDark)) return BiomeScene.SILENT;
            kind = BiomeScene.DEEP_DARK;
            intensity = 1f;
            // `sub` = scuttle count per 30 s, capped at 2.
            sub = 1f;
        } else if (biome.is(BiomeTags.IS_SNOWY) || biome.is(Biomes.ICE_SPIKES) || biome.is(Biomes.FROZEN_OCEAN)
                || biome.is(Biomes.DEEP_FROZEN_OCEAN) || biome.is(Biomes.SNOWY_BEACH) || biome.is(Biomes.SNOWY_TAIGA)
                || biome.is(Biomes.SNOWY_PLAINS) || biome.is(Biomes.SNOWY_SLOPES)) {
            if (!FoleyClient.wants(FoleyConfig::snowyHush)) return BiomeScene.SILENT;
            kind = BiomeScene.SNOW;
            // Intensity ramps with celsius: full at -10 °C, half at 0 °C, off at 5 °C.
            intensity = celsius < 5f ? Math.max(0f, 1f - (celsius + 10f) / 15f) : 0f;
            if (intensity <= 0f) return BiomeScene.SILENT;
            // `sub` = leaf exposure, 0 to 1 (0 open, 1 under trees).
            var wind = FoleyClient.wind();
            sub = wind == null ? 0f : Math.min(1f, wind.scene().leaves());
        } else if (biome.is(Biomes.MANGROVE_SWAMP)) {
            if (!FoleyClient.wants(FoleyConfig::mangroveDrone)) return BiomeScene.SILENT;
            kind = BiomeScene.MANGROVE;
            // Count mangrove leaves in a 24-block radius around the player.
            int leaves = io.github.cumsauce.foley.audio.MangroveLeaves.count(level, BlockPos.containing(player.getEyePosition()), 24);
            intensity = 1f;
            sub = Math.min(200f, leaves);
        }
        if (kind < 0) return BiomeScene.SILENT;
        // Apply the umbrella gate.
        if (!FoleyClient.wants(FoleyConfig::biomeBeds)) return BiomeScene.SILENT;
        return new BiomeScene(kind, intensity, sub, 1f);
    }
}
```

import net.minecraft.client.multiplayer.ClientLevel;
import net.minecraft.core.BlockPos;
import net.minecraft.world.level.block.Blocks;
import net.minecraft.world.level.chunk.LevelChunk;
import net.minecraft.world.level.chunk.LevelChunkSection;

public final class MangroveLeaves {
    private MangroveLeaves() {}
    public static int count(ClientLevel level, BlockPos center, int radius) {
        int count = 0;
        for (int cx = (center.getX() - radius) >> 4; cx <= (center.getX() + radius) >> 4; cx++) {
            for (int cz = (center.getZ() - radius) >> 4; cz <= (center.getZ() + radius) >> 4; cz++) {
                LevelChunk chunk = level.getChunk(cx, cz);
                for (int sy = level.getMinY() >> 4; sy <= level.getMaxY() >> 4; sy++) {
                    LevelChunkSection section = chunk.getSection(level.getSectionIndexFromSectionY(sy));
                    if (section.hasOnlyAir()) continue;
                    for (int y = Math.max(sy << 4, center.getY() - 8); y <= Math.min((sy << 4) + 15, center.getY() + 8); y++) {
                        for (int x = Math.max(cx << 4, center.getX() - radius); x <= Math.min((cx << 4) + 15, center.getX() + radius); x++) {
                            for (int z = Math.max(cz << 4, center.getZ() - radius); z <= Math.min((cz << 4) + 15, center.getZ() + radius); z++) {
                                if (section.getBlockState(x & 15, y & 15, z & 15).is(Blocks.MANGROVE_LEAVES)) count++;
                            }
                        }
                    }
                }
            }
        }
        return count;
    }
}

## Review Focus

These inputs/failure modes are implied by the spec but no test exercises them; they go here once, and the tests that pin them live in the listed task:

- **Bed cap.** A `BiomeController` runs one bed; that's fine, but a player standing exactly on a biome border flickers between two beds. Pin in Task 3 by adding `assertEquals(1, controller.bedCount())` to a multi-biome test (skipped — only one bed is possible, the spec is explicit).
- **Desert vortex rings.** Vortex rings only when `U > 8 m/s`. With `sub = 0` the test renders no rings. Pin in Task 1 by setting `sub = 2` and counting vortex envelopes (skipped — the test renders *something* but doesn't time vortex events).
- **Mangrove leaf count.** A 200-block cap protects against the count climbing in a dense mangrove. Pin in Task 3 by setting `sub = 500` and asserting the scene clamps it.
- **Deep dark scuttle count.** A scuttle every 30 s; cap at 2 per 30 s. Pin in Task 1 by rendering 60 s of audio and counting scuttle envelopes.
- **Snow intensity ramp.** The intensity goes from 1 at -10 °C to 0 at 5 °C; a player in a snowy biome with high celsius (impossible in vanilla, but mods exist) gets a silent bed. Pin in Task 3 by setting `celsius = 5.0f` and asserting `intensity = 0`.
- **Toggle off.** A config with all 7 toggles off should round-trip through `FoleyConfig.fromJson(...).toJson()`. Pin in Task 4 by extending `FoleyConfigTest` to assert each toggle's value survives a round-trip.
- **Bed kind bounds.** A scene with `kind = 7` (out of range) should be rejected. Pin in Task 2 by feeding `foley_bed_set_scene(bed, [7.0, 1.0, 0.0, 1.0], 4)` and asserting `FOLEY_ERR_INVALID_ARGUMENT`.
- **Player underground in a biome that has no sky-light.** The biome's ambient bed shouldn't play. Pin in Task 3 by making the controller's `sample` return `SILENT` when `!hasSkyLight`.
