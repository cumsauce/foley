# M13 — More Birds Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plugins to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Expand Foley's bird catalogue from 9 to ~35 species and make each biome sound like itself by replacing `Life.pickBird`'s weighted pick with a per-biome roster. The existing syrinx engine grows FM, trills, inhaled chips, rattles, croaks, hoots, a `drum(rate_hz, decay_s)` helper, and a `Phrase` builder so the new species are descriptive data. The original 9 still match under engine 2 (spectrogram correlation > 0.9) — engine 2 is a vocabulary extension, not a rewrite.

**Architecture:** A new `engine2` module in `crates/foley-synth/src/birds/engine2.rs` adding the primitives. The existing `crates/foley-synth/src/birds.rs` keeps `Bird` and `bird_call` but routes the original 9 through a hand-checked migration that uses only the new vocabulary (FM, trills, etc., as needed) and stays within the audibly-tolerable spectrogram correlation. A new `Birds` enum (~35 variants) and a `bird_call2(Bird, seed)` for the new ones. The Java side keeps the existing `Life.CROW`/etc. constants for the original 9, adds a new `BiomeRoster` table generated by `scripts/gen_birds.py` alongside `gen_voices.py`, and `pickBird` is replaced by a roster lookup.

**Tech Stack:** Rust (foley-synth, foley-ffi), Java 21 (mod), Python 3 (codegen), Gradle, cbindgen.

**Spec:** `docs/PLAN.md` lines 496–549 (M13 plan).

- `FOLEY_SHOT_BIRDSONG`'s `size` argument is the species index. Today it's `0..=8` (the original 9). M13 widens the range to `0..=Birds::ALL.len() - 1`. The Java `GeneratedSounds` switch's `case "bird" ->` already takes `n` from the variant name (`bird_<n>`), so widening the range is a one-line ABI change in `crates/foley-ffi/src/lib.rs` (the range check).
- `gen_birds.py` is added next to `gen_voices.py`. It reads the Rust `Birds` enum, writes a Java `BiomeRoster` class with the same structure as `VoiceTable` (data not code), and adds the `bird_<species>` entries to `sounds.json`.
- Each species renders 12 variants (the existing `n = 12` pattern in `gen_voices.py`).
- A new setting `rarerSpecies` (boolean, default false) gates Kori bustard, golden eagle, alpine chough and the like. It's a settings field, not a per-species knob.
- The existing `Life.birdActivity`, `Life.pickBird` and `Bird.Bird.ALL` references in the codebase all stay valid; `pickBird` is replaced by `BiomeRoster.pick(biome, celsius, rarer)`.

```rust
/// Frequency-modulated note, depth and rate in Hz, seconds.
pub fn fm(contour: &[(f32, f32)], fm_depth_hz: f32, fm_rate_hz: f32, seconds: f32, harmonic: f32,
         (attack, release): (f32, f32), rng: &mut Rng) -> Vec<f32>;

/// A trill: rapid AM-modulated sweeps, ~8 to 12 Hz, on a base note.
pub fn trill(base_hz: f32, sweep_hz: f32, seconds: f32, am_hz: f32, rng: &mut Rng) -> Vec<f32>;

/// A short broadband burst, 5 to 10 ms, at high pitch.
pub fn chip(centre_hz: f32, q: f32, rng: &mut Rng) -> Vec<f32>;

/// A Poisson of `chip` calls: a rattle (snow bunting, varied thrush).
pub fn rattle(centre_hz: f32, rate_hz: f32, seconds: f32, rng: &mut Rng) -> Vec<f32>;

/// A croak/rasp: short, low-pitch pulses with strong breath noise.
pub fn croak(pulse_count: usize, base_hz: f32, breath_db: f32, rng: &mut Rng) -> Vec<f32>;

/// A long pure-tone pulse with a slow decay (boreal owl, great grey owl, snowy owl).
pub fn hoot(centre_hz: f32, seconds: f32, rng: &mut Rng) -> Vec<f32>;

/// Drum at `rate_hz` strikes/s for `decay_s` seconds (Gila woodpecker, spruce grouse).
pub fn drum(rate_hz: f32, decay_s: f32, rng: &mut Rng) -> Vec<f32>;

#[derive(Clone, Copy, Debug)]
pub enum Segment { Whistle(...), Trill(...), Chip(...), Rattle(...), Croak(...), Hoot(...), Drum(...), Fm(...) }

/// A list of segments rendered in sequence. Each is `[kind, parameters, duration]`.
pub struct Phrase { pub segments: Vec<Segment> }

impl Phrase {
    pub fn new(segments: Vec<Segment>) -> Self;
    /// Render to PCM at SAMPLE_RATE. Seeded by `seed` for any per-segment randomness.
    pub fn render(&self, seed: u64) -> Vec<f32>;
}
```

- [ ] **Step 3: Implement `fm`, `trill`, `chip`, `rattle`, `croak`, `hoot`, `drum`, `Phrase`**

Implementation notes (the implementer follows the existing `whistle`, `harsh`, and `add_at` patterns from `crates/foley-synth/src/birds.rs`):

- `fm` generalises `whistle` with a sinusoidal modulator on the frequency: `f = contour_at(t) + fm_depth * (TAU * fm_rate * t).sin()`.
- `trill` sums a sine at `base_hz` with an AM envelope: `g = 0.5 + 0.5 * (TAU * am_hz * t).sin()`.
- `chip` is a short burst of band-passed noise at `centre_hz` (use `BandPass::new(centre_hz, q)`), 5–10 ms, with a fast attack and exponential release.
- `rattle` is a Poisson of `chip` calls at `rate_hz` for `seconds`, each at a slightly different `centre_hz` (uniform ±200 Hz).
- `croak` is `pulse_count` short low-pitch pulses with breath noise injected, each ~30 ms, attack 5 ms.
- `hoot` is a sine with a slow amplitude envelope (a 100 ms attack, an exponential decay with τ = seconds/3).
- `drum` is `decay_s × rate_hz` taps of `contact(Contact::Tap, Material::Wood, 6.0, seed)`, each at 1/rate spacing, with a falling amplitude envelope.

```rust
#[test]
fn engine2_matches_engine1_within_audible_tolerance() {
    for bird in Bird::ALL {
        for seed in 0..6 {
            let v1 = engine1::bird_call(bird, seed);
            let v2 = bird_call(bird, seed);
            // Align lengths to the shorter.
            let n = v1.len().min(v2.len());
            let v1 = &v1[..n]; let v2 = &v2[..n];
            // Normalised correlation. Power ∑x², covariance ∑xy.
            let p1: f32 = v1.iter().map(|x| x*x).sum();
            let p2: f32 = v2.iter().map(|x| x*x).sum();
            let cov: f32 = v1.iter().zip(v2).map(|(a,b)| a*b).sum();
            let corr = cov / (p1.sqrt() * p2.sqrt()).max(1e-9);
            assert!(corr > 0.9, "{bird:?} seed {seed}: {corr}");
        }
    }
}
```

```java
private int pickBird(Holder<Biome> biome, float celsius) {
    var roster = BiomeRoster.ROSTERS.get(biome.unwrapKey().orElseThrow().location().toString());
    if (roster == null || roster.isEmpty()) return -1; // river, ocean — no birds
    int total = roster.stream().mapToInt(e -> e.weight()).sum();
    int roll = random.nextInt(total);
    int acc = 0;
    for (var e : roster) {
        acc += e.weight();
        if (roll < acc) {
            if (e.rare() && !FoleyClient.config().rarerSpecies()) {
                // Rarer species are off; fall back to the commonest species in the same roster.
                return Birds.ALL.indexOf(roster.get(0).species());
            }
            return Birds.ALL.indexOf(e.species());
        }
    }
    return Birds.ALL.indexOf(roster.get(0).species());
}
```
