# M17 — Surf as a Placed Bed Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the discrete 6–12 s surf one-shots with one continuous `FOLEY_BED_SURF` streaming bed that models a shore's wave cycle, so a stormy beach is a continuous crashing wash and a calm lake laps quietly.

**Architecture:** A new streaming synth `Surf` in `crates/foley-synth/src/surf.rs` that owns the wave cycle: a continuous low shingle/foam wash whose level follows the scene, with `outdoors::surf(height, seed)` grains scheduled by the bed itself at a rate set by wind × storm. Java's `SurfController` samples distance-to-water, beach/open direction, storm level and wind speed once every `SAMPLE_EVERY` ticks and drives one `BedSound<SurfScene>`; `Life.java`'s surf one-shot firing is removed so the two never double up.

**Tech Stack:** Rust (`foley-synth`, `foley-ffi`), Java 21 (mod, Fabric 1.21.x), cbindgen (`cargo xtask header`).

**Spec:** `docs/PLAN.md` lines 595–606 (M17 plan).

## Global Constraints

- Bump `FOLEY_ABI_VERSION` from **22 to 23** in `crates/foley-ffi/src/lib.rs` and (via `cargo xtask header`) `crates/foley-ffi/include/foley.h`; bump the Java mirror `NativeBridge.ABI_VERSION` to 23 in lockstep. Java refuses a library whose version differs.
- New bed kind `FOLEY_BED_SURF = 9` (next free bed id — 0–8 are taken: RAIN 0 … BIOME 8). Do not renumber any existing constant.
- `FOLEY_SHOT_SURF = 6` stays as-is for the **API path** (`AddonSounds` `SoundModel.Surf`); only `Life.java`'s internal one-shot firing is removed. The existing shot is not deleted — addon packs still use it.
- Wave heights keep the spec's tiers: `Life.SURF_M = {0.3f, 1.0f, 2.2f}` (lake lapping / calm sea / rough sea). The bed's height comes from the same three-tier logic.
- Scene floats: the bed takes **4 floats** `{height, shore, storm, exposure}` following the `BiomeScene { kind, intensity, sub, gain }` precedent — every scalar clamped to 0..1 except `height`, which is the wave height in metres (0.2 to 3.0), matching the shot's existing range guard.
- The bed must render silence when `height <= 0` (the `Biome` short-circuit pattern, `biome.rs:188-193`) so an inactive shore bed costs nothing.
- One placement: a *single* `BedSound<SurfScene>` (not `SurroundBeds`) — surf is one broad source, and the 8-stream budget must not be spent four times over.
- No new `FoleyConfig` toggle: M17 is covered by the existing `water` toggle (`FoleyClient.wants(FoleyConfig::water)`), which already gates the one-shot it replaces.
- All new Java follows the `audio` package's file naming and the `WindController`/`BiomeController` tick pattern.

## Review Focus

- **A listener who never moves.** The bed must not fall silent when the player stands still on a shore for minutes: the wave cycle is time-driven, not movement-driven. (Pinned in Task 1 by `waves_keep_coming_without_a_moving_listener`.)
- **Leaving the shore.** Walking 100 m inland must stop the bed promptly and leave no stuck stream — the stop path is as important as the start path. (Pinned in Task 4 by `far_from_water_stops_the_bed`.)
- **Two shores, one cut.** A beach at the edge of an ocean and a lake both report water nearby; the height tier must come from the biome, not from whichever water block the scan hit first, or a stormy coast reads as a calm lake. (Pinned in Task 3 by `salt_water_raises_the_height_lake_does_not`.)
- **Shelter under a storm.** Standing under an overhang on an exposed shore: the spec asks for a continuous bed, so the surge rate should still follow the wind the *wind bed* reports, not a locally re-measured wind that reads zero under cover. (Pinned in Task 3 by `surgeRateRisesWithStormAndWind` — the exposure argument is the wind bed's reported speed; Task 3's sampler must read `FoleyClient.wind().scene().speed()` and never re-measure wind locally.)
- **Fresh water versus salt at the same wind.** The spec requires a lake to be gentler than an ocean under identical conditions; the tier must come from the biome tag, not the wind. (Pinned in Task 3 by `saltWaterRaisesTheHeightLakeDoesNot` and `aStormRaisesTheHeightOnlyForSaltWater`.)
- **The seam between one wave and the next.** Grains are 7 s and a storm's surge interval is ~2 s, so grains overlap; the bed must mix overlapping grains without clipping or a periodic click at each boundary. (Pinned in Task 1 by `overlapping_waves_stay_bounded_and_seamless`.)

**Interfaces:**

```rust
/// What the Java side tells the shore bed about the listener.
#[derive(Debug, Clone, Copy)]
pub struct SurfScene {
    /// Wave height in metres (0.2 to 3.0); 0 = no shore, renders silence.
    pub height: f32,
    /// 0 to 1: how close the listener is to the water's edge.
    pub shore: f32,
    /// 0 to 1: rain and thunder above the shore.
    pub storm: f32,
    /// 0 to 1: the wind the wind bed reports (never a locally re-measured wind).
    pub exposure: f32,
}

/// One shore bed. Streams the wave cycle: a continuous shingle/foam wash
/// under `outdoors::surf` grains scheduled at a rate set by storm x exposure.
#[derive(Debug)]
pub struct Surf { /* seed, scene, grain phase, scheduler state */ }

impl Surf {
    pub fn new(seed: u64) -> Self;
    pub fn set_scene(&mut self, scene: SurfScene);
    pub fn render(&mut self, out: &mut [f32]);
}
```

`render` is mono, one sample per element of `out`, like `Biome::render` (`biome.rs:187`). `SAMPLE_RATE` comes from the crate root (`use crate::SAMPLE_RATE;`). The wave cycle: grains of `outdoors::surf(height, grain_seed)` are started when the scheduler's interval elapses, where the interval in seconds is `map(storm * exposure)` from about **12 s (calm)** to **2 s (full storm)** (the spec's "a stormy sea is `surf(2.2, …)` crashing every 2 s"); each started grain plays out its full ~7 s while new ones may start, so grains overlap and must be summed and soft-clipped. The continuous wash under them is band-passed noise whose level follows `shore` and `height` (the foam/shingle the spec names), mixed at a level well below the grains.

```rust
#[cfg(test)]
mod tests {
    use super::*;

    fn scene(height: f32, storm: f32, exposure: f32) -> SurfScene {
        SurfScene { height, shore: 1.0, storm, exposure }
    }

    fn render_secs(s: &mut Surf, secs: f32) -> Vec<f32> {
        let mut out = vec![0.0f32; (secs * crate::SAMPLE_RATE as f32) as usize];
        s.render(&mut out);
        out
    }

    #[test]
    fn silent_with_no_shore() {
        let mut s = Surf::new(1);
        s.set_scene(scene(0.0, 1.0, 1.0));
        let out = render_secs(&mut s, 3.0);
        assert!(out.iter().all(|x| *x == 0.0), "a bed with no shore must render silence");
    }

    #[test]
    fn a_calm_shore_still_sounds() {
        let mut s = Surf::new(2);
        s.set_scene(scene(0.3, 0.0, 0.0));
        let out = render_secs(&mut s, 5.0);
        let rms = (out.iter().map(|x| x * x).sum::<f32>() / out.len() as f32).sqrt();
        assert!(rms > 1e-4, "a calm lake must still lap, rms {rms}");
    }

    #[test]
    fn a_storm_has_more_surges_than_a_calm_sea() {
        // Count envelope peaks above a threshold over 60 s.
        fn peaks(mut s: Surf, storm: f32) -> usize {
            s.set_scene(scene(2.2, storm, 1.0));
            let out = render_secs(&mut s, 60.0);
            let win = (crate::SAMPLE_RATE / 10) as usize;
            let mut over = false;
            let mut n = 0;
            for chunk in out.chunks(win) {
                let r = (chunk.iter().map(|x| x * x).sum::<f32>() / chunk.len() as f32).sqrt();
                if r > 0.02 && !over { n += 1; over = true; }
                if r <= 0.02 { over = false; }
            }
            n
        }
        let calm = peaks(Surf::new(3), 0.0);
        let storm = peaks(Surf::new(3), 1.0);
        assert!(storm > calm, "storm surges {storm} must exceed calm {calm}");
    }

    #[test]
    fn waves_keep_coming_without_a_moving_listener() {
        // No scene change after the first: the cycle must not stall.
        let mut s = Surf::new(4);
        s.set_scene(scene(1.0, 1.0, 1.0));
        let out = render_secs(&mut s, 120.0);
        let last = &out[out.len() - crate::SAMPLE_RATE as usize..];
        let rms = (last.iter().map(|x| x * x).sum::<f32>() / last.len() as f32).sqrt();
        assert!(rms > 1e-3, "waves must keep arriving while standing still, rms {rms}");
    }

    #[test]
    fn overlapping_waves_stay_bounded_and_seamless() {
        let mut s = Surf::new(5);
        s.set_scene(scene(2.2, 1.0, 1.0));
        let out = render_secs(&mut s, 90.0);
        assert!(out.iter().all(|x| x.is_finite() && x.abs() <= 1.0), "output must stay in range");
        // No single-sample jump larger than a step within a wave.
        let max_step = out.windows(2).map(|w| (w[1] - w[0]).abs()).fold(0.0f32, f32::max);
        assert!(max_step < 0.5, "a click at a grain boundary, max step {max_step}");
    }

    #[test]
    fn a_higher_wave_is_louder() {
        let mut low = Surf::new(6);
        low.set_scene(scene(0.3, 0.5, 0.5));
        let mut high = Surf::new(6);
        high.set_scene(scene(2.2, 0.5, 0.5));
        let r = |v: &[f32]| (v.iter().map(|x| x * x).sum::<f32>() / v.len() as f32).sqrt();
        let lo = render_secs(&mut low, 20.0);
        let hi = render_secs(&mut high, 20.0);
        assert!(r(&hi) > r(&lo), "a 2.2 m sea must beat a 0.3 m lap");
    }
}
```
